# 🚀 ToDo App

A modern and interactive ToDo application built with JavaScript. Users can add, complete, and delete tasks, with data automatically saved in the browser's local storage.

## 🔗 Live Demo
https://pervane-dev.github.io/todo-app/

## ✨ Features

- ✅ Add new tasks
- ✅ Mark tasks as completed
- ✅ Delete tasks
- ✅ Save data in browser (Local Storage)
- ✅ Responsive design

## 🛠 Tech Stack

- HTML5
- CSS3
- JavaScript (ES6)

## 📂 Installation

```bash
git clone https://github.com/pervane-dev/todo-app.git
cd todo-app
```

Open `index.html` in your browser.
